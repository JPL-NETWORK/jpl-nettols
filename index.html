Una dirección, dos partes

El prefijo indica cuántos bits identifican la red. El resto identifica las direcciones dentro de esa red. En una subred convencional se reservan la dirección de red y la de broadcast.

02 / PLANIFICACIÓN

Cada VLAN, su espacio.

VLSM

Reparte una red entre varias subredes, empezando por las más grandes.

Conserva la numeración original de tus VLAN. Reserva red y broadcast en cada bloque; para 2 hosts utiliza /30.
